下载时的经验

  • LibreCAD 只读 DXF，打不开 DWG。想出 DWG 得靠 LibreDWG 转换。
  • DWG 转换三个坑：MTEXT 降级成 TEXT；标注炸开并把文字改成左对齐绝对坐标； DXF 存 R2000 且设 $DWGCODEPAGE=ANSI_936，否则中文变成 \U+XXXX。
  • 静默安装走 PowerShell Start-Process '/S','/D=D:\路径'，bash 直接跑 exe 会被拒。
  • 外部依赖先到 GitHub 查四项：维护活跃度 / star / 许可证 / 有无已知漏洞。

一级目录装什么

三个刻意不改名的目录

  • 软件 —— 有桌面快捷方式直接指向内部 exe，改名会断链。
  • 软件数据 —— 程序正在实时读写的缓存，改名会让软件报错。
  • CAD —— C 盘 AppData 的 LibreCAD 配置是 junction 过来的，改名会断开。

  • D 盘回收站是坏的 —— SHFileOperation 返回成功但文件没进去，或直接被删。 删东西一律走「移到备份目录 + 还原清单」。
